## Local Setup

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or later
- [Yarn](https://yarnpkg.com/) v1.x

### Getting Started

1. Install dependencies:

   ```sh
   yarn install
   ```

2. Start the app:

   ```sh
   yarn start
   ```

The app will be available at `http://localhost:3000`.

## Built on Backstage

Command Center is powered by [Backstage](https://backstage.io), an open-source developer portal platform created by Spotify and donated to the CNCF. Backstage provides the foundation for building a centralized hub where engineering teams can discover services, manage infrastructure, and access tooling — all in one place.

Key capabilities inherited from Backstage include:

- **Software Catalog** — track and manage all your services, libraries, websites, and pipelines
- **TechDocs** — centralized technical documentation, written as code alongside your projects
- **Plugin ecosystem** — extend the portal with a rich library of community and custom plugins
- **Scaffolder** — standardize project creation with golden-path software templates
